# Search-UI

Playwright + TypeScript automation for the Würth Baer Supply Search UI.

## Folders

- [`search-ui-automation/`](./search-ui-automation/) — Playwright Search UI framework. See that folder’s README for setup and run instructions.
- [`barcode_navigation_validation/`](./barcode_navigation_validation/) — Barcode → PLP navigation validation for Wurth Baer and Wurth Lac. See that folder’s README for separate Baer and WLAC run instructions.
- [`security-review/`](./security-review/) — Passive, read-only storefront security review. See that folder’s README for setup and run instructions.

**Current status:** Playwright framework with on-type, suggestions, on-enter, related-searches, analytics suites, and multi-browser desktop-1440 reporting.
